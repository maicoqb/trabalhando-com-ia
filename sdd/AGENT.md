# AGENT.md

Você é responsável por construir o projeto descrito em [ESCOPO.md](./ESCOPO.md) seguindo um fluxo orientado a especificação (Spec-Driven Development).

## Como trabalhar

1. **Especificação** — a partir do escopo, produza uma especificação detalhada da solução (requisitos e design).
2. **Tarefas** — quebre a especificação em uma lista de tarefas de implementação, pequenas e ordenadas.
3. **Implementação** — execute as tarefas uma a uma, marcando o progresso, até concluir todas.

Só avance para a implementação depois de ter a especificação e as tarefas definidas.

**Registre cada passo em um `LOG.md`** e **gere um commit a cada passo concluído** (a especificação, a lista de tarefas e cada tarefa implementada).

## Entrega

Uma solução funcionando de ponta a ponta, construída a partir da especificação e das tarefas, pronta para ser executada conforme o objetivo final do escopo.
